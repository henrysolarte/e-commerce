  ├─ GET    /api/categories          Listar todas

  Clientes
  ├─ GET    /api/customers           Listar todos
  ├─ POST   /api/customers           Crear cliente
  ├─ PUT    /api/customers/{id}      Actualizar
  └─ DELETE /api/customers/{id}      Eliminar

🔐 SEGURIDAD
───────────────────────────────────────────────────────────────────────────────

✅ Spring Security integrado
✅ Autenticación JWT (JSON Web Tokens)
✅ Autorización basada en roles (ROLE_ADMIN, ROLE_USER)
✅ Contraseñas encriptadas
✅ Token expiration configurado

Flujo de Seguridad:
1. Usuario hace login con credenciales
2. Backend valida y genera JWT token
3. Token se guarda en localStorage del cliente
4. Token se incluye en todas las peticiones (Authorization: Bearer <token>)
5. Backend valida el token en cada petición

❌ TROUBLESHOOTING RÁPIDO
───────────────────────────────────────────────────────────────────────────────

PROBLEMA: "Connection refused" al iniciar backend
SOLUCIÓN: Asegurar que PostgreSQL está corriendo en localhost:5432

PROBLEMA: "Database 'ecommerce' does not exist"
SOLUCIÓN: Ejecutar en PostgreSQL: CREATE DATABASE ecommerce;

PROBLEMA: "Port 8081 already in use"
SOLUCIÓN: Cambiar en application.properties: server.port=8082

PROBLEMA: "JAR not found"
SOLUCIÓN: Ejecutar: cd back && mvnw clean package -DskipTests

PROBLEMA: CORS error al conectar frontend
SOLUCIÓN: Añadir @CrossOrigin a los controllers

Para más detalles: ver CONEXION_BD.md
